          MachineIts health, its memory and disk; restart, sleep.
          

            
Health

            
    
            
    
            
    
              
              
            
    
            
    
            
    When its tool starts
    
            
    
            
    Each time its machine starts (a wake after a stop, a restart), the tool takes up the session it had, as it was. Start fresh: it starts a new one, with nothing of before in mind.
    
            
    
            
            
    
            
    Ask before acting
    
            
    
            
    Off (the default): the tool acts without asking you, with every right inside its own machine: it installs, changes and deletes there as it sees fit. Outside its machine it reaches only what you attached to it, as you attached it. On: it asks you before it acts, as it does by itself. Taken into account the next time the tool starts: restart the machine to apply it now.
    
            
    
            
    Memory and disk
    
            
    
              
              
              
              
              
    Changing them stops the machine cleanly, sets them and starts it again: its work folder, folders and branches stay. A disk can only grow.

          AdvancedReady-made machine, git server keys.
          
      
          
      
            Ready-made machine
            
      New conversations start from a copy of a machine prepared in advance, with the tools already installed: a minute or two instead of several. It is rebuilt each month in the background; running conversations are not touched.
      
            
      
            
      
            
      
          
      
          
      
            Git servers whose key is recorded
            
      The first time a git server is reached over ssh, the key it shows is recorded; a different key later is refused, because the server may not be who it says. If a hosting service really changed its key (it says so on its own site), forget it here: the next contact will trust whatever key the server shows.
