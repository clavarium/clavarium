Sign-in mailbox

          
A mailbox used only for this tool's account. When its provider sends a sign-in link there, the link appears next to the terminal. The mailbox is read, never changed; its password stays on the host and never enters the machine. Use an app password where the mail provider offers one.

          Add a repository
          
A folder that starts as a repository: empty, or cloned from an https address. It is attached and shared like a folder, to read or to write. What the tool commits stays in it; pushing elsewhere is the tool's business, with what you hand it.

Storage & backup

        
Each conversation works in a disk of a fixed size (10 GB unless the installation says otherwise). A backup is made on the machine itself, as two files -- the archive, and the key of the vault apart: sudo deploy/backup.sh --to /a/folder.
