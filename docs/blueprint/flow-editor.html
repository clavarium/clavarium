Set it up by drawing it

A mock-up. Boxes are agents, folders and people; a link says who reads and who writes.

How to use it

A link from an agent to a folder: it writes there. From a folder to an agent: it reads. An arrow at both ends: both. Drag a box to move it. To link two boxes, pull a wire from the small circle of one and drop it on the other, or touch the circle, then the other box. Touch a box or a link to change it.
