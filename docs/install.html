Install Clavarium on your server

One command on Ubuntu. The local install asks nothing, and it updates itself at night.

Try it first

Install on your server, in one line:

curl -fsSL https://clavarium.org/install.sh | sudo bash

Read the script · This machine only, no sign-in. From your computer:

ssh -L 7717:127.0.0.1:7717 you@that-machine

Then open http://127.0.0.1:7717

Online, with your domain

DOMAIN=<your-domain> EMAIL=<your-email> curl -fsSL https://clavarium.org/install.sh | sudo bash -s -- --domain "$DOMAIN" --admin "$EMAIL" --relay-user ubuntu
  1. It shows a key. Give it to a small relay machine.
  2. Point your domain to the relay.
  3. Open your address. Sign in.

Ports 80 and 443 open? Use --direct, no relay.

What it needs

  • Ubuntu Server 24.04 or 26.04, on an x86_64 CPU that runs VMs.
  • 1–2 GB RAM per working agent. Tried on 4 cores, 6 GB.
  • A domain, and your AI: a subscription or a provider key.

Clavarium and its core programs are named releases, checked against a checksum. Read the script

Limits

  • Ubuntu Server only, for now.
  • What an agent reads goes to its AI provider.

Questions

Is it free?

Yes, MIT. Clavarium brings no AI and charges nothing.

No public address at home?

Your machine dials out to the relay. Home opens no port.

How do I upgrade?

It updates itself at night by default. Do not re-run this on an online server.
