Short answers

Will my setup still work later?

Yes, and you stay free: change AI in one setting, in the same conversation, with the same files. Built to last.

Which agents does it run?

Claude Code, Codex, OpenCode, Gemini CLI, Mistral Vibe, or a shell. Any terminal agent can run from the Shell.

Does my code or mail leave my server?

Clavarium does not send it elsewhere. Its AI provider gets what the agent reads, and an online agent can send it on.

Can an agent read the keys I give it?

That agent only. The push key and mail passwords never enter any machine.

What stops an agent that goes wrong?

It touches only what you gave it to write. Nothing is sent with your keys unless you allowed it.

Do I have to read a terminal?

No. Chat with it in Parley, or use the simple screen.

Does it work on a phone?

Yes. The page installs as an app, with alerts.

What does it cost?

Nothing: MIT. You pay your server, your AI subscription or provider, and a domain if you go online.

Can several people use it?

Yes, but operators see everything. To share one conversation, use a QR code; you can revoke it.

How is it different from a container?

A container shares the host's kernel. Here each agent has a VM, and the push key and mail passwords stay outside.

What is not there yet?

See the Roadmap.
