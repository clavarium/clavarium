Feature

Connect your tools to your AI agents

Tether: mail, calendar, browser, MCP. A level per access, you approve, Stop cuts it all.

  • MailGoogle, Microsoft, IMAP
  • CalendarGoogle, Microsoft, CalDAV
  • ContactsGoogle, Microsoft, CardDAV
  • Browser tabsThrough an extension
  • TerminalsA computer, or SSH
  • Online filesRead, write, move
  • MCP serversAny, over HTTP
  • Voice boxesSpeak, listen, play
  • The agent never holds a password, token or API key.
  • A waiting call shows the exact command: Accept, Refuse, Always.
  • Watch, Propose, Frame or Free: a level per access.

Limits

  • At Free level the agent acts without asking. The journal still says all.
  • Not answered in time, a call is refused.

Questions

What does the journal keep?

Who, where, what exactly, the decision, when. Never a secret or a file's content.

Can I add my CRM's MCP server?

Yes. Added once, its key stays with Tether, rights set per conversation.

Is it tied to Clavarium?

No. Tether is its own MIT project.

Install on your server, in one line:

curl -fsSL https://clavarium.org/install.sh | sudo bash
