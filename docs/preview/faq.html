Short answers

Which agents does it run?

Claude Code, Codex, OpenCode, Gemini CLI, Mistral Vibe, or a shell. Any terminal agent can be added.

Does my code or mail leave my server?

It stays there. What an agent reads goes to the AI model it uses.

Can an agent read the keys I give it?

That agent only. The push key and mail passwords never enter any machine.

What stops an agent that goes wrong?

It touches only what you gave it to write. Nothing is sent with your keys without you.

Do I have to read a terminal?

No. Chat with it in Parley, or use the simple screen.

Does it work on a phone?

Yes. The page installs as an app, with alerts.

What does it cost?

Nothing: MIT. You pay your AI subscription or provider, as today.

Can several people use it?

Yes. Several operators sign in, and one conversation can be shared with a QR code, then revoked.

How is it different from a container?

A container shares the host's kernel. Here each agent has a VM, and keys stay outside.

What is not there yet?

See the Roadmap.
