# Credits

Clavarium uses, at run time, work by others under open licences. Thank you.

## Voices of the voice boxes

- **Pocket TTS** by **Kyutai** (https://kyutai.org) — the voice by default. Program: MIT. Model weights:
  CC-BY-4.0 (https://huggingface.co/kyutai/pocket-tts). French voice « estelle »: CC0. Fetched at run time
  from Kyutai's releases and Hugging Face; not shipped in this package.
- **Piper** voices (https://huggingface.co/rhasspy/piper-voices), run by **sherpa-onnx** (Apache-2.0) — the
  fallback voice. Each voice keeps its own licence (see its model card).
- **ElevenLabs** — optional, with the owner's own key.

## Sound

- **FFmpeg** (https://ffmpeg.org) — reads radios and recordings, levels and slows sounds; run as a separate
  program, installed by the system.
