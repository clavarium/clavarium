# clavarium

Keeps the name until the Clavarium server is published under it.

Clavarium: each AI agent in its own machine, with only what you attach. A terminal and a chat in a web page.

- Site: https://clavarium.org
- Source: https://github.com/clavarium/clavarium

Running `npx clavarium` prints where it is and exits. It runs nothing else and reaches no network.
