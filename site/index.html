Your agents work all night. Nothing leaves without you.

Each sees only what you attach and uses keys it cannot read. In the morning, the report is on your tablet.

  • Free · MIT
  • Open source
  • On a machine you own
  • Claude Code, OpenCode, any other
  • Each client kept apart
  • Agents wake each other

How you use it

  1. 01You tell each agent its job

    You attach one client's orders and write one plain line each. One wakes at 2:00, the other when a request arrives.

    Client: Bakery
    report Claude Code
    orders read · shared write · shop key use
    Every night at 2:00 · read the day's orders, write the report, ask for the chart
    ↓ shared / request.md ↓
    charts OpenCode
    shared write
    When a file arrives in shared · do the request
    Client: Garage · its own agent, its own key, not seen from here

  2. 02They answer only if all agree

    Models from different makers read its question. All agree: it goes on. One doubts: it stops, touches nothing, and waits for you.

    report Claude Code03:12
    38 orders read. The report is half written.
    Shall I go on? (y/n) y
    model A yesmodel B yesmodel C yes
    03:40 Delete last week's reports? (y/n)
    A yesB noC yeswaiting for you
    Tonight: answered 4, waited on 1. Limit: 5 in a row. All in the log.

  3. 03You read it on a tablet, then send

    The report opens as a plain page. Nothing goes out until you press Send, with a key the agent never holds.

    Bakery report, Monday38 orders, 3 late.
    2 commits to shop
    nothing sent yet    Send

Instead of cron, tmux and glue

A cron job runs a script. This wakes an agent that can ask, be answered, hand work to another, and still cannot send anything without you.

How you install it, and what it needs

One command, once, on an Ubuntu machine you own. After that, you only open a page.

sudo deploy/install.sh \
  --domain clav.example.com \
  --operator you@example.com
  • A small machineUbuntu Server 24.04 or 26.04, on a processor that can run virtual machines. A mini PC does.
  • 1 GB of memory per agent at workand a few GB of disk each. An agent asleep costs no memory.
  • The agents you already usewith your own subscription. Nothing to pay here.

Where it was built and tried: 4 cores, 6 GB of memory, 40 GB of disk.
